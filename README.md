I started this 8 Week SQL Challenge created by Danny Ma to build upon the basic SQL skills I gained from the HarvardX's CS50’s Introduction to Databases with SQL course. This challenge has elevated my SQL skills from beginner to intermediate, where I became more comfortable with planning my approach to questions, creating cleaner structures, and encountering more advanced commands and syntax such as:
- `CASE` statements
- Selecting the appropriate multi-table joins
- Date/time manipulation
- String formatting
- `OVER, PARTITION BY` window functions
- Common table expressions
- Data cleaning and transformation
