# Case Study #3: Foodie-Fi
## Part C. Challenge Payment Question
Link to [DB Fiddle](https://www.db-fiddle.com/f/rHJhRrXy5hbVBNJ6F6b9gJ/811) to execute the queries shown below

The Foodie-Fi team wants you to create a new payments table for the year 2020 that includes amounts paid by each customer in the subscriptions table with the following requirements:
- monthly payments always occur on the same day of month as the original start_date of any monthly paid plan
- upgrades from basic to monthly or pro plans are reduced by the current paid amount in that month and start immediately
- upgrades from pro monthly to pro annual are paid at the end of the current billing period and also starts at the end of the month period
- once a customer churns they will no longer make payments
```sql
DROP TABLE IF EXISTS payments;

CREATE TEMPORARY TABLE payments AS 
WITH RECURSIVE month_recur AS (
    SELECT customer_id,
        plan_id,
        plan_name,
        CASE
            WHEN LEAD(start_date) OVER(PARTITION BY customer_id ORDER BY start_date) IS NULL
                AND LAG(plan_id) OVER(PARTITION BY customer_id ORDER BY start_date) = '1'
                THEN price - LAG(price) OVER(PARTITION BY customer_id ORDER BY start_date)
            ELSE price END
            AS amount,
        start_date AS payment_date,
        CASE
            WHEN LEAD(start_date) OVER(PARTITION BY customer_id ORDER BY start_date) IS NULL THEN '2020-12-31'
            ELSE LEAD(start_date) OVER(PARTITION BY customer_id ORDER BY start_date) END
            AS last_date
    FROM subscriptions
        JOIN plans USING(plan_id)
  
UNION ALL
  
    SELECT customer_id,
        plan_id,
        plan_name,
        amount, 
        (payment_date + INTERVAL '1 month')::DATE AS payment_date,
        last_date
    FROM month_recur
    WHERE payment_date + INTERVAL '1 month' <= last_date::DATE
        AND plan_id NOT IN ('3', '4')
)
SELECT customer_id,
    plan_id,
    plan_name,
    amount,
    payment_date,
    last_date,
    ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY payment_date) - 1 AS payment_order
FROM month_recur
WHERE EXTRACT(YEAR FROM payment_date) = 2020
ORDER BY customer_id, payment_date, plan_id;
```
